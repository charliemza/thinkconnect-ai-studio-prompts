# 📦 Plantilla de Repositorio para Google AI Studio & GitHub

Este repositorio contiene la estructura optimizada para ser importado directamente en **Google AI Studio** (`Build` -> `+` -> `Import from GitHub`).

## 📁 Contenido:
* `system_instructions.md`: Instrucciones del sistema y reglas de comportamiento de Gemini.
* `prompt_template.json`: Plantilla JSON del prompt con parámetros de inferencia y placeholders de variables.
* `.env.example`: Plantilla de variables de entorno y API keys para despliegue local o cloud.
* `.gitignore`: Exclusiones para evitar subir credenciales o carpetas de entorno.
